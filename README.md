# learn-web

A learning project for modern frontend web development. I'm building a habit tracker step by step, starting with plain HTML and JavaScript, then moving to React, TypeScript, and Next.js.

## Project layout

- `habit-tracker/` - the app. Currently `index.html` (structure) and `app.js` (behavior).
- `LEARNING.md` - progress log: concepts learned, shaky topics, glossary.
- `.gitignore` - files Git should ignore (IDE settings in `.idea/`).

## Running the habit tracker

No tools are needed yet. Open `habit-tracker/index.html` in a browser.

To see JavaScript errors, press F12 and open the Console tab.

## Roadmap

1. Plain HTML, CSS, JavaScript (in progress)
2. React with Vite
3. TypeScript (strict)
4. Next.js App Router
5. Tailwind, Zod, Vitest, Playwright, NextAuth, passkeys, Stripe, Turnstile, security headers
6. Backend: Prisma, PostgreSQL, Supabase, webhooks
